# מדריך צילומי מסך לגוגל פליי
# Screenshots Guide for Google Play Store

---

## 📐 דרישות גוגל פליי

| פריט | דרישה |
|------|-------|
| כמות מינימלית | 2 צילומים |
| כמות מומלצת | 4–8 צילומים |
| גודל מינימלי | 1080 × 1920 פיקסל (פורטרט) |
| גודל מקסימלי | 3840 × 3840 פיקסל |
| פורמט | PNG או JPEG |
| גודל קובץ | עד 8MB לצילום |
| יחס גובה/רוחב | לפחות 16:9 (פורטרט: 9:16) |

> ⚠️ **חשוב:** גוגל מציגה את הצילומים בחנות. ככל שהם יפים יותר — יותר אנשים יורידו את האפליקציה.

## 🎯 אילו מסכים לצלם — רשימה מומלצת (8 צילומים)

### 📸 צילום 1 — מסך בחירת מנוע (onboarding)
**מסך:** `app/index.tsx` — מסך הפתיחה שבו בוחרים מנוע A או B
**מה מראה:** שני הכפתורים הגדולים — "🔊 בלי קריאה" ו-"📖 עם קריאה"
**למה חשוב:** המסך הראשון שרואה המשתמש — חייב להיות בצילום

---

### 📸 צילום 2 — מסך הבית מנוע A (גריד תמרורים)
**מסך:** `app/(engineA)/(tabs)/home.tsx`
**מה מראה:** גריד של אייקוני נושאים צבעוניים
**למה חשוב:** מראה את הממשק הויזואלי/קולי — ייחודי לאפליקציה

---

### 📸 צילום 3 — מסך הבית מנוע B (רשימת נושאים עם טקסט)
**מסך:** `app/(engineB)/(tabs)/home.tsx`
**מה מראה:** רשימת נושאים עם שמות באמהרית ופסי התקדמות
**למה חשוב:** מראה את הממשק הטקסטואלי — לקהל שיודע לקרוא

---

### 📸 צילום 4 — מסך תמרור עם הסבר
**מסך:** `app/(engineA)/sign/[id].tsx` — תמרור ספציפי עם תמונה והסבר
**מה מראה:** תמונת תמרור + כפתור 🔊 + הסבר באמהרית
**למה חשוב:** מראה את לב האפליקציה — לימוד תמרור בודד

---

### 📸 צילום 5 — מסך שאלה/חידון
**מסך:** `app/(engineA)/question/[id].tsx` — שאלת בחירה מרובה
**מה מראה:** תמונת תמרור + שאלה + 4 תשובות אפשריות
**למה חשוב:** מראה את מנגנון הלמידה האינטראקטיבי

---

### 📸 צילום 6 — מסך נושא התנהגותי
**מסך:** `app/(engineA)/behavioral/[topicId].tsx`
**מה מראה:** רשימת תתי-נושאים (בטיחות, חוקים וכו')
**למה חשוב:** מראה שהאפליקציה עוסקת גם בנושאים מעבר לתמרורים

---

### 📸 צילום 7 — מסך פרוגרס/התקדמות
**מסך:** `app/(engineA)/(tabs)/progress.tsx`
**מה מראה:** פסי התקדמות לפי נושאים, כמה תמרורים נלמדו
**למה חשוב:** מראה שהאפליקציה עוקבת אחרי ההתקדמות

---

### 📸 צילום 8 — מסך תוצאות בחינה (עם קונפטי)
**מסך:** `app/result/[sessionId].tsx` — תוצאה עם עבר ✅
**מה מראה:** ציון גדול, קונפטי, כפתורי חזרה/ניסיון חוזר
**למה חשוב:** מסך ה"וואו" — מראה שהאפליקציה גם מהנה ומעודדת

## 🖥️ שיטה 1 — צילום מאמולטור אנדרואיד (מומלצת)

### שלב 1: התקן Android Studio
1. הורד מ: developer.android.com/studio
2. התקן עם הגדרות ברירת מחדל
3. פתח את Android Studio

### שלב 2: צור אמולטור
1. בתפריט העליון לחץ **Tools → Device Manager**
2. לחץ **"Create Device"**
3. בחר: **Pixel 6** (מכשיר פופולרי)
4. בחר גרסת Android: **API 34** (Android 14)
5. לחץ **"Finish"**

### שלב 3: הפעל את האמולטור
1. לחץ על ▶️ ליד הנכשיר שיצרת
2. המתן עד שהאמולטור עולה (2-3 דקות)

### שלב 4: הרץ את האפליקציה על האמולטור
פתח טרמינל חדש:

```
שלב א:
cd C:\Users\Yakov\Desktop\driving-theory-app
לחץ Enter

שלב ב:
npx expo start
לחץ Enter

שלב ג:
כשהמסך עולה, לחץ על המקש A (להריץ על Android)
```

האפליקציה תיפתח על האמולטור.

### שלב 5: צלם מסך מהאמולטור
שיטה א — מכפתור באמולטור עצמו:
- בצד ימין של האמולטור יש כפתור 📷 (Camera icon)
- לחץ עליו — הצילום יישמר אוטומטית

שיטה ב — מ-Android Studio:
- **View → Tool Windows → Logcat**
- בחלון שנפתח לחץ על אייקון 📷

שיטה ג — קיצור מקשים:
- **Ctrl + S** (בחלון האמולטור הפעיל)

**הצילומים נשמרים ב:** `C:\Users\[שם-משתמש]\Pictures\`

## 📱 שיטה 2 — צילום ממכשיר אנדרואיד אמיתי

### שלב 1: הפעל USB Debugging במכשיר
1. לך ל-**הגדרות → אודות הטלפון**
2. לחץ 7 פעמים על **"מספר build"** עד שיופיע "Developer mode enabled"
3. חזור להגדרות → **אפשרויות מפתח**
4. הפעל **USB Debugging**

### שלב 2: חבר את המכשיר
1. חבר כבל USB בין המחשב למכשיר
2. במכשיר יופיע: "Allow USB debugging?" — לחץ **Allow**

### שלב 3: הרץ את האפליקציה
```
שלב א:
cd C:\Users\Yakov\Desktop\driving-theory-app
לחץ Enter

שלב ב:
npx expo start
לחץ Enter
```

האפליקציה תופיע אוטומטית על המכשיר (או לחץ A בטרמינל).

### שלב 4: צלם מסך
- **לחץ בו-זמנית:** כפתור הדלקה + כפתור הורדת עוצמה
- הצילום יישמר בגלריה

## 🎨 שיטה 3 — עיצוב Professional עם Canva (אופציונלי אבל ממליץ!)

גוגל פליי מציגה Screenshot Frames — אפשר לעטוף את הצילומים במסגרת מכשיר יפה עם כותרת.

1. לך ל-canva.com
2. חפש "Google Play Screenshot Frame"
3. בחר תבנית, הכנס את הצילום שלך, הוסף כיתוב קצר באמהרית
4. הורד בגודל 1080×1920

**כיתובים מומלצים לכל צילום:**
| צילום | כיתוב מומלץ |
|-------|------------|
| מסך בחירת מנוע | "בחר את סגנון הלמידה שלך" |
| מנוע A גריד | "למד בקלות — רק תמונות וקול" |
| מנוע B רשימה | "קרא והבן — כל תמרור בפירוט" |
| תמרור עם הסבר | "135+ תמרורים עם הסבר באמהרית" |
| שאלת חידון | "תרגל עם חידונים אינטראקטיביים" |
| נושאים התנהגותיים | "גם נושאי בטיחות וחוקי תנועה" |
| פרוגרס | "עקוב אחרי ההתקדמות שלך" |
| תוצאות בחינה | "בדוק את עצמך — כמו בחינה אמיתית" |

## 🖼️ Feature Graphic (חובה!)

גוגל פליי דורשת גם **Feature Graphic** — באנר רחב שמופיע בחלק העליון של הדף.

| פריט | דרישה |
|------|-------|
| גודל | **1024 × 500 פיקסל** (רוחב × גובה) |
| פורמט | PNG או JPEG |
| תוכן | שם האפליקציה + תמונה מייצגת |

**איך ליצור:**
1. לך ל-canva.com
2. צור עיצוב בגודל מותאם: 1024×500
3. הוסף:
   - רקע בצבע כחול/ירוק (צבעי האפליקציה)
   - שם האפליקציה: **መንጃ ፍቃድ**
   - כיתוב: **"ምልክቶቹን ተማር — ፈተናን አልፍ"**
   - אייקון תמרור קטן או תמונת מסך
4. הורד כ-PNG
