## כללים חשובים שנלמדו:

### תוכן ההסבר:
- משפטים **פשוטים** — לא מילים מורכבות
- לא לחזור על מילים מאותו שורש באותו משפט
- לא להשתמש בצורות פועל מורכבות (כמו "ቀስቱ ለሚያሳየው")
- אם יש בחירת נתיבים לפי 813/926 — **חובה לכלול בהסבר**
- שאלה שה-explanation_correct שלה ריקה (רק prefix) — לתקן ידנית
- ⚠️ **אסור לקצר את המידע שהמשתמש שולח** — להעביר את כל המידע לסקריפט כמות שהוא, ללא קיצורים, אלא אם המשתמש נתן הוראה מפורשת לקצר

### טיפול בשגיאות:
- אם explanation_correct = רק prefix — לתקן ידנית עם משפט ברור
- אם צריך להוסיף מידע להסבר בלבד (לא לשאלות) — לעדכן רק signs.json, למחוק רק את קובץ ה-explanation.mp3, לרוץ generateAllAudio ולהעלות

### לאחר שהמשתמש בודק ומאשר:
1. שאל: "האם בדקת את האפליקציה ועובדת תקין?"
2. לאחר "כן" — git add content/signs.json + commit + push
