# כלל: נקה שדות ישנים לפני עדכון תמרור

## הכלל:
לפני כל הרצת סקריפט תיקון (fixWithContext.mjs / updateSignFromMoT.mjs / כל סקריפט אחר),
**חובה לנקות את השדות הישנים הבאים ב-signs.json:**
- `name_amharic` → הגדר ל-`""`
- `explanation_amharic` → הגדר ל-`""`
- `questions` → הגדר ל-`[]`

וגם ב-Supabase:
- מחק את כל השאלות הישנות של התמרור מטבלת `questions`

## למה:
תוכן ישן (שגוי) ב-Amharic fields עלול להטעות את Gemini ולגרום לתוצאות שגויות.
אם השדות ריקים — Gemini מייצר תוכן חדש לחלוטין על בסיס ההקשר שנמסר.

## מתי זה חל:
- כל פעם שמתקנים תמרור שההסבר/שאלות שלו שגויים
- לפני כל הרצה חוזרת של סקריפט על תמרור שכבר עובד עליו
