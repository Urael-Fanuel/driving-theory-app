# תהליך שמירה ב-GitHub — חובה לבצע

## הכלל הברזל:
כאשר המשתמש שואל "תשמור בגיטהאב":
1. שאל: "האם בדקת את האפליקציה ועובדת תקין?"
2. ברגע שהמשתמש עונה "כן" — שמור מיד ב-GitHub **ללא המתנה להודעה נוספת**
3. לאחר ה-push, עדכן: "✅ נשמר"

## אסור:
- לחכות להודעה נוספת כמו "עדכן אותי כשתסיים" לפני שמתחילים לשמור
- לשמור לפני קבלת אישור "כן" מפורש מהמשתמש

## הסדר המדויק:
משתמש: "תשמור בגיטהאב"
→ Claude: "האם בדקת את האפליקציה ועובדת תקין?"
→ משתמש: "כן"
→ Claude: מבצע git add + commit + push **מיד**
→ Claude: "✅ נשמר"
